# 🛡️ КиберЩит

Веб-платформа и браузерное расширение для защиты пользовательских данных.

## 📦 Что внутри

- **Веб-сайт** — методики, обзор программ, форум, личный кабинет
- **Браузерное расширение** — проверка сайтов на фишинг, генератор паролей, год создания домена

## 🛠️ Технологии

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js, Express
- **База данных:** SQLite
- **Расширение:** Manifest V3, HTML, CSS, JavaScript

## 🚀 Запуск

### 1. Установка зависимостей
\`\`\`bash
npm install
\`\`\`

### 2. Запуск сервера
\`\`\`bash
node server.js
\`\`\`

Сайт откроется на [http://localhost:3000](http://localhost:3000)

### 3. Установка расширения
1. Открой \`chrome://extensions/\`
2. Включи «Режим разработчика»
3. Нажми «Загрузить распакованное расширение»
4. Выбери папку \`extension\`
